# Asset provenance

## Social card

`public/og.png` is an original AI-generated branded card, generated for Runline using the built-in image generation tool. Dimensions: 1536 × 1024. It was visually inspected for the requested title and supporting copy before integration. It contains no customer data or real event information.

Design brief: a cohesive landscape social preview for “Runline”, with the headline “Your event, in sync.” and supporting text “Human + agent. One shared plan.” Use an off-white paper background, forest-green typography, sage schedule blocks with restrained lavender and amber accents, an editorial product identity, and clear legible text. No browser chrome, fake customer logos, credentials, or dense dashboard screenshot.

The in-app controls and favicon are code-native functional UI. Interface icons are from Lucide; retained shadcn components use Base UI. Geist and Geist Mono are provided through the framework's font integration. Third-party assets and packages retain their original licenses.
